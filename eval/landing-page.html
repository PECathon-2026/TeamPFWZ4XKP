Defense-in-Depth

Cryptographic & Architectural Guarantees

PrivacyLens does not merely prompt LLMs to ignore secrets. It enforces strict mathematical, architectural, and runtime boundaries.

The Single Egress Chokepoint (FR-D1)

Exactly one function in the entire extension codebase is permitted to call fetch(): sendThroughGate(). Before any byte touches the wire, it passes through 4 validation gates: Schema Validation, Destination Allowlists, Redaction Ledger Check, and Broad Tripwire Pattern Scans. Any violation triggers an immediate, fail-closed circuit break.

// apps/extension/src/egress/gate.ts
if (tripwireScan(serializedPayload).detected) {
  throw new GateTripwireError("GATE_TRIPWIRE_TRIGGERED: Aborting wire egress");
}

Mathematical Checksums

Luhn mod-10 with IIN brand checks (Visa, Mastercard, Amex, RuPay) and Verhoeff dihedral $D_5$ algorithms for Indian Aadhaar eliminate false-positive collision while guaranteeing 100% recall.

Anti-TOCTOU Element Binding (FR-C4)

Consequential actions (payments, deletions) require Tier-2 human consent. Actions are cryptographically bound to element accessible names, tag names, and form targets—preventing mutation attacks.

AES-256-GCM Secret Vault (FR-C6)

Secrets are stored in WebCrypto AES-GCM encrypted storage. The model only receives masked references (e.g. vault://card.number). Raw secrets are injected exclusively at execution time inside the client.

Visual Default-Deny (FR-B5)

Multimodal screenshot capture automatically enforces solid opaque #000000 fill masking over <video> feeds, <canvas>, and cross-origin frames. Reversible blur and pixelation are strictly forbidden.

Questions & Answers

Frequently Asked Questions

Everything you need to know about the security model and deployment requirements.

Which LLM providers are supported?

PrivacyLens is model-agnostic. It works out of the box with Anthropic Claude 3.5 Sonnet, OpenAI (GPT-4o, o1), Ollama local models, and any OpenAI-compatible inference gateway.

How are raw payment cards filled into inputs?

The agent never receives raw numbers. It outputs a vault reference such as vault://card.number. The extension's client-side Action Validator decrypts the secret locally and dispatches trusted DOM events.

Can malicious web pages tamper with the redactions?

No. Visual redaction badges are mounted using Closed Shadow DOM (attachShadow({ mode: "closed" })). Host page JavaScript cannot inspect or traverse the shield root.

What is the latency overhead of local redaction?

Local redaction latency is measured under 15ms (typically 0.8ms - 2.5ms) using optimized Luhn and Verhoeff implementations, adding negligible overhead to agent step cycles.
